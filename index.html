Características

Todo lo que necesitas en una plataforma

Herramientas diseñadas para optimizar la gestión odontológica universitaria

Búsqueda Inteligente

Encuentra pacientes por tipo de tratamiento, edad o disponibilidad con filtros avanzados.

Sistema de Solicitudes

Envía y gestiona solicitudes entre estudiantes y pacientes de forma organizada.

Chat en Tiempo Real

Comunicación instantánea entre estudiante y paciente una vez aceptada la solicitud.

Gestión de Citas

Programa, confirma y gestiona citas odontológicas con estados claros y seguimiento.

Historial Clínico

Registro detallado de tratamientos realizados con fechas, estados y observaciones.

Calificaciones

Sistema de reputación donde los pacientes pueden calificar a los estudiantes.

Notificaciones

Alertas en tiempo real sobre solicitudes, citas y mensajes nuevos.

Reportes PDF

Genera reportes académicos de citas y tratamientos en formato profesional.

Seguridad

Autenticación segura, protección por roles y políticas de seguridad a nivel de base de datos.

Cómo Funciona

Proceso simple en 4 pasos

Desde el registro hasta la atención, todo en un flujo claro y organizado

1

Registro

El estudiante y el paciente se registran en la plataforma con sus datos

2

Solicitud

El estudiante busca pacientes y envía una solicitud de atención

3

Conexión

El paciente acepta y se habilita el chat y el sistema de citas

4

Atención

Se agenda la cita, se realiza el tratamiento y se registra el historial

Acerca del Sistema

Arquitectura del Sistema

Desarrollado con tecnologías modernas, seguras y fáciles de mantener

Frontend

HTML5, CSS3 y JavaScript puro. Sin frameworks complejos. Código limpio y organizado.

Backend (MVC)

Node.js + Express con arquitectura MVC. Supabase como BaaS: auth, DB y realtime.

Base de Datos

PostgreSQL con Row Level Security (RLS) para protección a nivel de fila.

Información del Proyecto

Universidad: UNERG

Facultad: Odontología

Tipo: Proyecto de Grado II

Área: Informática

Autenticación: Supabase Auth (JWT)

Seguridad: RLS + Validaciones

Comunicación: WebSocket (Realtime)

Almacenamiento: Supabase Storage
